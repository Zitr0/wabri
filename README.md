# Wabri — Web Agent Bridge

Extensión de Chrome que convierte el chat de IA que ya usas (Copilot Chat, ChatGPT o DeepSeek) en un agente que trabaja en la página que tú eliges, paso a paso y con tu aprobación.

Este repositorio solo publica la **política de privacidad** de la extensión y recibe preguntas. El código de Wabri no se publica aquí.

- **Política de privacidad:** [PRIVACY.md](PRIVACY.md) · [versión web](https://zitr0.github.io/wabri/PRIVACY.html)
- **Preguntas o problemas:** abre un [issue](https://github.com/Zitr0/wabri/issues).
- **Apoya el proyecto:** [Buy Me a Coffee](https://buymeacoffee.com/supportprojects)

Wabri es un proyecto independiente y no está afiliado a Microsoft, OpenAI ni DeepSeek. Todos los derechos reservados.
